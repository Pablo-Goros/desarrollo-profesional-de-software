# Diseño de software

## Overview

El software se presenta como un modelo computable de un dominio de problemas de la realidad. El diseño es parte del proceso que transforma el conocimiento del dominio en código. [OFF-002, p. 3]

## Conceptos centrales

El análisis parte de lenguaje natural: es informal, incompleto y puede contener conocimiento tácito. En cambio, el código es el documento formal, completo y explícito con precisión suficiente para construir el sistema; los diagramas expresan conocimiento de manera explícita, pero son informales e incompletos. [OFF-002, pp. 4-6]

El desarrollo de software es un proceso de aprendizaje iterativo e incremental: genera conocimiento a partir de hechos concretos y requiere organizarlo. [OFF-002, p. 7]

La clase enfatiza que el código es el documento principal de diseño. Como prácticas de código limpio, propone nombres pronunciables y buscables, métodos que hagan una sola cosa y evitar la duplicación; ante código malo, plantea corregirlo en lugar de comentarlo. [OFF-002, p. 8]

## Relaciones

La [orientación a objetos](orientacion-a-objetos.md) ofrece un paradigma para expresar el diseño. La [arquitectura de software](arquitectura-de-software.md) organiza las decisiones estructurales del sistema, y los [principios SOLID](principios-solid.md) guían las dependencias entre clases.
